# Stremio Digital Releases Addon

Self-hosted Stremio addon for digital movie releases.

## Deploy

1. Upload files to GitHub.
2. Create a Render Web Service.
3. Use:

Build command:
npm install

Start command:
npm start

4. After deployment open:

https://YOUR-RENDER-URL/manifest.json

5. Paste that link into Stremio Add-ons.

## Features

- Digital release catalog
- Rent tracking
- Buy tracking
- Streaming availability fields
- Daily updater framework
